현재 세션의 한도 해제 시각에 작업 재시작을 자동 예약한다.

## 흐름

1. **사용자에게 확인** — "세션 한도가 가까워졌습니다. 지금까지 작업을 정리하고 이어서 예약할까요?"

2. **continuation_plan.md 작성** — 프로젝트 루트(`./continuation_plan.md`)에 기록한다. 스크립트가 이 경로를 자동으로 읽는다:
   ```markdown
   # 세션 연속 계획 — {날짜 HH:MM}

   ## 완료
   - ...

   ## 중단 위치
   - 파일/함수/단계: ...

   ## 다음 세션에서 할 일
   1. ...

   ## 주의사항
   - ...
   ```

3. **예약 실행** — 추정 시각으로 즉시 실행한다:
   ```bash
   python3 scripts/schedule_continuation.py
   ```
   스크립트가 출력하는 리셋 시각과 남은 시간을 사용자에게 그대로 전달한다.
   예: "22:05에 재시작 예약했습니다 (3시간 15분 후)."

4. **시각 수정** — 사용자가 다른 시각을 알려주면 `--reset-at`으로 다시 실행한다:
   ```bash
   python3 scripts/schedule_continuation.py --reset-at HH:MM
   ```

## 금지사항
- continuation_plan.md 없이 예약만 하지 마라 — 재시작 시 컨텍스트가 사라진다.
- 사용자에게 리셋 시각을 먼저 물어보지 마라 — 추정값으로 먼저 실행하고, 틀리면 수정한다.
- 세션 ID를 수동 입력하거나 추측하지 마라 — 스크립트가 자동 감지한다.
